# ETF / 指数 MACD 回测与 512760 通知

一个合并后的单容器项目：

- 浏览器页面用于沪深 ETF 和 `88xxxx` 同花顺指数的 MACD 日线回测，例如半导体指数 `881121`。
- 后台任务仅监控 `512760`，使用固定 MACD `(12,26,9)`，工作日 `14:55` 检查并通过 Server酱通知。

回测页面的 MACD 参数可以调整，但不会改变后台通知参数。

“历史行情”CSV 导出包含日期、每日开盘价、收盘价、每日成交量（手）、DIF、DEA 和 Histogram。ETF 价格沿用前复权口径；成交量为所查标的自身的成交量，统一为手（100 股/份），缺失数据留空。导出覆盖所选日期范围的全部已完成日线，不受当前分页限制。

逐笔交易新增“大 A 成交量 / 成交额”列，在同一单元格分别显示实际买入日、卖出日的沪深合计成交量（亿股）和成交额（亿元），不含北交所；尚未卖出的持仓只显示买入日数据。服务端从东方财富获取历史日线并按日期严格匹配，缺失显示 —，盘中数据注明盘中；支持手动刷新及 CSV 导出。服务端缓存 60 秒。

逐笔交易顶部列出最近一次已买入、未卖出的持仓，显示买入日期、买入价、最新估值价、浮动收益和持仓估值，CSV 同步导出。未成交买入信号单独标注“待买入”；次日卖出尚未成交时仍显示持仓。浮盈亏仅扣买入手续费，不计入已完成交易的收益、胜率和年度统计。ETF 盘中日 K 不作为最终收盘信号，实时开盘价可执行昨日信号，最新价用于持仓估值；设置历史结束日期时按该日期截断回测，不使用未来卖出数据。

页面顶部“成交方式”默认选择“当天卖出、次日集合竞价买入”：买入信号确认后按下一交易日开盘价模拟买入，卖出信号按当天收盘价模拟卖出。也可选择原有的“当天收盘”或“次日开盘（集合竞价模拟）”，切换后立即重算。当天收盘成交属于理想化回测；开盘价仅用于模拟集合竞价，不保证实际成交。需要的开盘价缺失时不回退使用收盘价；尚未完成买卖的交易不计入统计。混合模式允许开盘买入当日出现卖出信号时按收盘价卖出，未模拟标的的 T+1 卖出限制。日期筛选按实际买卖日期，年度交易收益按卖出年份统计；逐笔资金及交易 CSV 同步使用选定方式。此选项不改变后台通知时间和信号规则。

## 红利低波股息率策略（独立页面）

MACD 回测之外新增的独立策略页面，不影响原有 MACD 回测与 512760 通知。入口：

- 左侧栏“策略”分组中的“红利低波股息率”，与“MACD 回测”使用同一套侧栏、工作区、标签栏和结果面板；
- 或直接访问 `http://localhost:8080/#dividend`（可加 `?tab=trades` / `?tab=dividends` 直接打开对应明细）。

标的与口径：

- 交易 ETF：`563020`（红利低波ETF易方达）；信号指数：`H30269`（中证红利低波动）；全收益指数：`H20269`。
- 股息率自算，不使用官方“股息率2”：
  - `F[t] = H20269[t] / H30269[t]`
  - `dividend_points[t] = H30269[t] × (F[t] / F[t-1] − 1)`
  - `DY[t] = sum(dividend_points[t-251 : t+1]) / H30269[t]`
  - 10 年分位：`DY[max(0, t-2519) : t+1]` 中 `≤ DY[t]` 的比例；有效历史不足 756 个交易日不产生信号，窗口最多 2520 个交易日；只使用当时已有数据。
- 五档仓位 `0 / 25 / 50 / 75 / 100%`。按当前档位重复检查触发条件，允许一次跨多档：
  - 0%：分位 ≥ 0.60 → 25%；
  - 25%：≥ 0.70 → 50%，≤ 0.40 → 0%；
  - 50%：≥ 0.80 → 75%，≤ 0.50 → 25%；
  - 75%：≥ 0.90 → 100%，≤ 0.60 → 50%；
  - 100%：≤ 0.70 → 75%。
- 每个自然月最后一个交易日收盘后计算，下一交易日收盘执行；未触发则继续持有。策略仓位按上次信号记录，实际资金仓位允许随价格漂移。

回测口径：

- 初始资金、单边成本（默认 `0.05%`）可调；ETF 买卖按 100 份整数倍。
- `563020` 上市（2023-12-14）前使用 `H20269` 全收益指数模拟，页面明确标注“指数模拟”，不是 ETF 实盘；全收益指数已含分红，不再叠加现金分红。
- 上市后使用腾讯不复权日线 + 天天基金现金分红记录：权益登记日持仓定权、除息日计入应收、发放日转为现金、发放日后下一交易日按 100 份整数倍再投资，避免把分红重复算进价格。
- 数据接口：`GET /api/dividend-basket` 聚合中证指数双序列与 563020 分红；服务端缓存 30 分钟，网络失败时回退到 `data/dividend-basket.json` 上次成功缓存。
- 净值图支持鼠标悬停：显示日期、策略/持有基准净值与权益、策略仓位、股息率与分位、当前处于 H20269 指数模拟还是 563020 实盘阶段。

历史案例（页面与测试均覆盖）：

- 2025-07-31 自算股息率 `4.408%`、10 年分位 `0.4472`，策略仓位从 `100%` 一次减到 `25%`，2025-08-01 收盘执行。
- 其他真实跨档案例：2010-05-31 分位 0.7016 `0% → 50%`；2011-06-30 分位 0.8440 `25% → 75%`；2025-07-31 `100% → 25%`。

代码位置：`web/src/dividend-strategy.js`（纯策略与回测）、`web/src/dividend-data.js`（行情/分红获取）、`web/src/dividend-page.js`（页面）、`src/dividend-basket.js`（服务端聚合与缓存）。测试：`test/dividend-strategy.test.js`、`test/dividend-basket.test.js`。

## 通知规则

- 昨日 Hist `<= 0` 且今日 `> 0`：BUY，标题“预翻红｜待收盘确认｜现价<价格>”。
- 昨日 Hist `>= 0` 且今日 `< 0`：SELL，标题“预翻绿｜待收盘确认｜现价<价格>”。
- 其他情况发送每日 MACD 状态，不产生交易信号。

当前微信通道的正文详情页会过期，所以标题本身带上关键数字。仅监控一个 ETF，标题不再重复代码和“每日 MACD”：无交易信号时为“<柱体状态>｜距翻红/翻绿<幅度>｜现价<价格>”，例如“绿柱变长｜距翻红25%｜现价0.865”。14:55 的翻色属于盘中估算，标题标记“预翻红/预翻绿”和“待收盘确认”。标题控制在 32 个字符内，优先保留状态和翻色距离，超长时先省略价格；手机仍可能折叠显示。失败报告标题为“今日MACD检查失败”。

每日状态包含最新价格、昨日/今日 Hist、柱体变长或缩短，以及按 14:55 行情反推的翻红/翻绿临界价格和所需涨跌幅。临界价格表示“当天价格取该值时 Hist 刚好等于 0”，是实时估算，不是未来走势预测。

行情默认读取东方财富；单次失败会自动重试三次，仍失败则切换到腾讯前复权日线并继续计算。两个行情源都连续失败时才发送“今日检查失败”。调度会跳过周末和交易所公布的 2026 年休市日。

最新日 K 不是当天、数据不足或行情获取失败时，会发送“今日检查失败”。任一报告成功发送后都会把日期和结果写入 `data/state.json`，防止同一天重复通知。

## 本地运行

要求 Node.js 22.12 或更高版本。

```bash
npm install
copy data\.env.example data\.env
npm run build
npm start
```

在 `data/.env` 中配置：

```dotenv
SERVERCHAN_SENDKEY=你的SendKey
```

访问 `http://localhost:8080`。`npm start` 会同时启动回测页面和通知调度器。

只开发回测页面时可运行 `npm run dev`；此命令不会启动通知任务。

## 测试

```bash
npm test
npm run test-notify
```

`test-notify` 会真实发送 Server酱测试消息。

## Docker / 极空间

直接构建并启动：

```bash
docker compose up -d --build
```

回测页面默认映射到 NAS 的 `8080` 端口。

极空间 ARM64 镜像：

```bash
docker buildx build --platform linux/arm64 -t macd-lab:arm64 --load .
docker save -o macd-lab-arm64.tar macd-lab:arm64
```

导入镜像后，在极空间 Compose 中使用 `compose.zspace.yaml`。它会把：

- `8080` 映射为回测页面端口；
- `/SATA存储11/macd` 挂载到容器 `/app/data`；
- `/SATA存储11/macd/.env` 保存 `SERVERCHAN_SENDKEY`；
- `/SATA存储11/macd/state.json` 保存通知去重状态；
- `/SATA存储11/macd/query-history.json` 保存页面最近查询记录。

在极空间的 `/SATA存储11/macd/.env` 写入：

```dotenv
SERVERCHAN_SENDKEY=你的SendKey
```

容器每次启动都会读取这个文件。换镜像或重建容器时，只要继续挂载同一个文件夹，SendKey、通知状态和搜索记录都不会丢失。

查看日志：

```bash
docker compose logs -f --tail=100
```

正常启动日志会同时出现：

```text
512760 MACD 通知服务已启动（Asia/Shanghai，工作日 14:55）
回测页面已启动：http://0.0.0.0:8080
```

> 回测结果和 MACD 通知仅供策略研究，不构成投资建议。
